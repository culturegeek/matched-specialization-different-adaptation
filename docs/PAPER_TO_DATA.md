# From manuscript claims to data

This map refers to the 15 October 2026 manuscript revision, identified by the checksum in [manuscript_version.json](../paper/manuscript_version.json). Paths below are relative to the repository root. Within an experiment, `results_confirm` (or `results_confirmatory`) identifies the stored confirmatory output; pilot directories remain separate.

All five figure families are generated by `scripts/make_figures.py`. The expected English PDFs are under `paper/figures`; regenerated PDFs are written to `generated/figures`. PDF metadata and font versions can change the binary checksum without changing the plotted values.

The portable arithmetic check covers 27 selected central means and the follow-up's 129-file frozen result manifest. It is not a complete independent reanalysis of every statistic in the appendices. The original per-study audits are included for those checks.
