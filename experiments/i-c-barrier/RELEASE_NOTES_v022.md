# Release notes v0.2.2

## 目的

v0.2.1で観測された共同更新の安定点候補について、その原因が共有推定器による方策遷移障壁かを検証する。

## 追加した比較

- 混合観測分布に一つの推定器を当てる共有条件
- 方策ごとに別の最適推定器を持つ専用条件
- Hamming距離1の全改善辺の連続走査
- 混合ペナルティ、障壁高、障壁位置、推定器固定時の切替費用の測定
- `phi=0`を時間結合のない対照として使用

## full結果

- `phi=0`：全96改善辺で障壁0
- `phi=0.4`：評価重みに応じ4〜5/32辺に障壁
- `phi=0.8`：評価重みに応じ16〜18/32辺に障壁
- `phi=0.8, lambda=0.5`：障壁18/32、最大障壁0.039801
- 専用推定器：全条件で障壁0

## 解釈

時間的に相関した観測では、決定的方策に適応した共有推定器が、混合方策の途中でどちらの観測分布にも最適化できなくなる。その一時的な性能低下が、より良い方策への経路にも山を作る。

これは共有推定器を仮定した場合の構成的結果であり、共有表現一般や人間の認知への直接的な実証ではない。

推定器は混合率ごとに最適化され、学習履歴を蓄積しない。したがって本実験が示すのは現在方策への適応が作る離脱費用であり、過去の観測頻度が表現へ不可逆に蓄積する成分ではない。
