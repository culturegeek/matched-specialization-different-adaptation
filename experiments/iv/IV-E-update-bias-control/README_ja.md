# IV-E 更新偏り追加対照

## 問い

取得条件、更新回数、平均的な損失配分が同じでも、各時点の更新重みの並び方だけで、形成後の学習しやすさは変わるかを調べる。

## 比較

- 一定更新：優位対象の損失重みを500回すべて0.80とする。
- 変動更新：優位対象の重みを1.00と0.60に各250回とし、seedごとに順序を無作為化する。

両条件の平均重みは0.80で一致する。A優位とB優位を鏡像条件とし、取得精度、学習データ順、mini-batch、更新回数、学習率をseed内で対応づけた。

## 確認結果

未使用40 seed（9300--9339）の確認実験で、表面上の形成終点は事前に定めた同等範囲内だった。一方、一定更新条件のAdam二次モーメント総量は変動更新条件の0.8215倍で、複合摂動に対する配分指数の変化量に0.0324（95% bootstrap区間0.0294--0.0354）の差が生じた。二次モーメントを交換すると差は$-0.0141$へ反転し、Adamを初期化すると0.0046まで縮小した。

この結果は、平均目的関数と最終性能が近くても、更新重みの時間配置がAdamに異なる勾配二乗履歴を残し、次の学習への感受性を変えたことを示す。元の取得主導／更新主導比較の差を、この一要因だけで全て説明したわけではない。

## 再現

```bash
python experiment_update_bias_control.py --mode confirm --output-dir results_confirm
python audit_update_bias_control.py --results results_confirm
```

数値と判定の正本は`results_confirm/` のCSV、`result.json`、`independent_audit.json`である。確認実験の設定と判定基準は`preregistration_confirmatory.json`に保存した。
