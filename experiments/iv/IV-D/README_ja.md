# 実験IV-D：形成経路と更新履歴

## 問い

取得精度の偏りによって形成した状態と、更新配分の偏りによって形成した状態を、方向指標とA/Bの復号誤差が近くなるように揃えたとき、通常継続と短い摂動への応答も同じになるかを調べます。

## 設計

- 形成前の同一checkpointから、取得主導経路と更新主導経路を作ります。
- 形成終点は、方向指標、対象側誤差、反対側誤差、誤差和、低精度測定の五項目について、事前に定めた同等範囲で照合します。
- 形成後は、中立継続、取得だけの短い反対摂動、更新だけの短い反対摂動、両者を合わせた摂動へ分岐します。
- 各条件を、形成時のAdam状態を保持する場合と、モデル重みを保ったままAdam状態だけを初期化する場合で比較します。

## 確認結果

- 形成終点の五項目は、すべて事前の同等範囲に入りました。
- 中立継続の差も、Adam保持・初期化の双方で同等範囲に入りました。
- Adam保持時の摂動応答差は、取得摂動0.1668、更新摂動0.1510、組合せ摂動0.1951でした。
- 組合せ摂動の転換率は、取得主導経路67.5%、更新主導経路0%でした。
- Adam初期化後の差は0.0011、0.0120、0.0103となり、三条件とも事前の同等範囲に入りました。

## ファイル

- `calibrate_iv_d.py`：形成終点を揃える強度のパイロット校正
- `experiment_iv_d.py`：確認実験本体
- `audit_iv_d.py`：実験モジュールと集計JSONを読まず、raw CSVから再集計する独立監査
- `preregistration_confirmatory.json` / `.md`：確認前に固定した条件、同等範囲、判定
- `results_confirm/`：確認実験のraw CSV、集計、独立監査結果

確認実験は未使用seed 8100--8139の40 seedを統計単位としました。中心結果の適用範囲は、小規模な二対象tanhネットワーク、Adam、有限時間の短い摂動です。
