# 実験IV 再現コード

実験IVは、情報取得と更新配分が共有表現の形成と形成後の移行へ与える効果を調べます。

- IV-A：形成済みcheckpointから取得先×更新先を交差させた実験。共通低雑音での再測定と中立継続を含みます。
- IV-B：形成前の同一checkpointから、取得方向3水準×更新配分3水準へ分岐した実験。パイロット、事前登録、未使用40 seedの確認、独立再集計を含みます。
- IV-C：更新配分で形成したA/B状態から、更新を均衡化し、取得方向だけを3水準で操作した実験。未使用40 seedの確認、独立再集計、実装監査で除外した実行の開発記録を含みます。
- IV-D：取得主導と更新主導で表面指標を揃え、通常継続と短い摂動応答を比較した実験。Adam状態の保持／初期化、未使用40 seedの確認、raw CSVからの独立監査を含みます。
- IV-E：モデルの重みを固定し、Adamの一次モーメントと二次モーメントを形成経路間で個別に交換した実験。追加対照では、取得、更新回数、平均更新配分を揃え、各時点の更新重みの時間配置だけを変えました。表面終点が近いまま、Adamの二次モーメントと短期応答が分かれることを確認しました。両実験とも未使用40 seedの確認、事前判定、raw CSVからの独立監査を含みます。

数値と判定の正本は、各結果ディレクトリのCSV、`result.json`、`independent_audit.json`です。IV-B/C/D/Eの確認コードと事前登録はSHA-256で固定されています。
