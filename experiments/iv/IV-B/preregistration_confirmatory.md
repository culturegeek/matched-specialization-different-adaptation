# 実験IV-B 確認実験の事前登録

固定日：2026年9月1日（確認seed実行前）

## 問い

AとBを同じ重みで学習していても、形成段階でどちらの情報を精密に経験するかによって、形成される共有表現の方向は変わるか。

## 中心比較

同じ初期checkpointから始め、更新重みをA/B=0.5/0.5に固定する。Aを精密に取得する条件と、Bを精密に取得する条件の、500更新後の方向指標を比較する。測定にはA/Bとも同じ高精度の未使用データを用いる。

中心効果は、`s(A精密, 均衡更新) - s(B精密, 均衡更新)` とする。

## 確認seedと統計単位

- 未使用40 seed：7200--7239
- 統計単位：seed
- 各seed内の9条件は、同じモデル、optimizer state、minibatch列から分岐する。
- bootstrap 5,000回、固定seed 20260901で平均の95%区間を求める。

## 合格条件

中心主張は、次の条件がすべて成立した場合に支持と判定する。

1. A精密取得とB精密取得が、それぞれ対応する信号の利用可能情報を増やす。
2. 取得を均衡にした陽性対照で、A重視更新とB重視更新の差が0.30以上、95%区間の下限が0を上回る。
3. 中心効果が0.30以上、95%区間の下限が0を上回る。
4. A精密・均衡更新の方向指標の95%区間下限が+0.10以上である。
5. B精密・均衡更新の方向指標の95%区間上限が-0.10以下である。

均衡取得・均衡更新の平均が `|s| <= 0.10` に収まることを中立性の操作確認とする。A/Bとも低精度で測った中心効果の95%区間下限が0を上回ることを、測定解像度に対する副次的一貫性検査とする。後者は中心主張の合否には含めない。

中心効果0.30は、方向指標の全範囲[-1,1]に対して十分に大きく、左右それぞれ平均0.15以上の形成差に相当する実質的基準として固定した。パイロット平均0.668の半分未満でありながら、単に符号が違うだけの微小効果を合格させない。

## 固定した実装

- 形成500更新、形成前の共通学習100更新
- bottleneck 2、hidden 32、Adam、学習率0.002
- 高精度noise SD 0.05、低精度1.20、形成前共通noise 0.15
- 更新重み：A重視0.85、均衡0.50、B重視0.15
- コードSHA-256：`5c2c52f56f1c5d2d5c21f5be946ac6a64f59b271a62ce47131972856e30643e7`

数値の機械可読な正本は `preregistration_confirmatory.json` とする。
