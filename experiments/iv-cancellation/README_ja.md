# 形成射影と二次モーメントの交差移植

問いは、形成中の勾配を変えて得た二次モーメントが、重みと一次モーメントを固定した学習器の応答を変えるか、である。未使用40 seedの二方向を用いた。encoderの二次モーメント総和は約1.42倍となり、その状態だけを元の学習器へ移すと10更新応答が約0.0472小さくなった。射影後の終点一致は未達である。

勾配射影は方向と大きさ、形成後の重みと状態を同時に変える。交差移植で二次モーメント供与の効果を切り分けるが、相殺だけを変える介入や自然な媒介割合の推定とは扱わない。

全計画、生記録、未達基準、区間、独立監査を保存した。許容幅の原計画との違いは protocol_clarification.json に明記し、固定済みファイルは変更しない。公開先では experiments/iv-cancellation/ に対応する。
