# 保存データによる照合

既知の結果を用いた探索的解析。新しい学習は行わない。元40 seedのS（累積個別勾配二乗）の取得−更新の対応差を層別に計算する。各群区間の重なりから差の有無を決めず、seed内対応差で判断する。観測精度別のcosと相殺比を全既存区間・両encoder層で集計する。条件付き観察を観測精度の因果効果と呼ばない。

保存checkpointはruns_generalの4設定とruns_betaの5設定、計9設定を全件使用する。beta×期間の格子は基準を含む6設定である。全パラメータ・encoder全体・第1・第2層のv総和と平均逆倍率を求め、方向内経路比の対数を方向内平均、seed間幾何平均とする。期間500→1500の経路比変化も同じseedの対応比で評価する。結果に応じて設定を選ばない。区間は10,000回seed bootstrap、乱数2026101703。
