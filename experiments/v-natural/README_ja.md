# V-C：三室の実測センサへの適応比較

三Gaussian対象で確認した成分効果が、自然な対象間関係と時間変動でも残るかを調べた。一住宅の台所・居間・洗濯室の温度と湿度へ観測雑音を加え、記録値を共有表現から再構成する。未来予測や元の家電エネルギー予測課題とは異なる。

8調整seedで部屋別の重みを選んだが、最良候補でも終点許容幅へ入らなかった。探索を追加せず、新規40 seed（36000–36039、容量間で共有）で確認した。終点は容量2で24基準中1、容量3で0のみ通過した。10更新のv交換効果は0.0854、0.1261、平均逆倍率を揃えた配置効果は0.0103、0.0257で、すべての区間が正だった。交換後の負対比は容量2だけで確認でき、容量3ではゼロをまたいだ。初期化と一次モーメント交換変化は許容幅内だった。自己状態対比が0.05を超える基準は容量2で未達だった。

結果が示すのは、実測値の制御課題で状態交換が適応を変えること。同等な終点の背後に応答差が隠れるという自然データ実証にはならない。区間は一住宅・固定時刻を条件とした学習と雑音の変動であり、住宅間の不確かさを含まない。全未達基準、全候補、六方向、50更新の二次評価を保持する。

再実行はREADME.mdの手順に従う。データの出典・CC BY 4.0表示はdata/ATTRIBUTION.md、時刻分割と学習時だけの標準化はdata/split_manifest.json、固定記録はregistration.json、判定正本はresults_confirm/result.json、独立監査はindependent_audit.jsonに置く。全1,859監査項目が通過した。固定結果を上書きせず、新規の出力先を使う。ローカル固定は公開レジストリでの事前登録とは区別する。
