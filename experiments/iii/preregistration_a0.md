# 実験III-A0 事前登録：環境・Oracle・観測・資源水準の校正

固定日: 2026-08-24  
対象: 有限状態の資源管理環境（地平10）

## 目的

1. 現在不足と将来障害リスクが競合する生成過程を構成する。
2. 生成過程を知る有限地平 Oracle を校正する。
3. 帰結ベクトル上の Pareto 構造を評価関数から独立に確認する。
4. 需要状態と設備状態を選択的に観測するチャネルを校正する。
5. 観測予算と表現スロットの拘束・非拘束水準を実測する。

## 事前判定

### G1 生成過程の健全性

- 全状態・全行為で遷移確率が非負。
- 各遷移行の総和と1との差が `1e-12` 以下。
- 全費用が有限かつ非負。

### G2 Oracle の有効性

- 競合環境の重み `0.25, 0.50, 0.75` の各条件で、Oracle のスカラー目的値が
  一様ランダム方策より相対的に10%以上低い。

### G3 帰結競合と帰無対照

- 競合環境では、101個の評価重みによる Oracle 解から得た非劣点が4点以上。
- 非劣点集合における現在不足の範囲が0.05以上、将来障害リスクの範囲が0.02以上。
- 帰無環境では、両帰結を同時に最小化する共通方策が存在し、二つの個別最小値との誤差が
  それぞれ `1e-10` 以下。

### G4 観測チャネルの選択性

- 需要センサ追加による需要状態の Bayes 正答率増分が0.20以上。
- 設備センサ追加による設備状態の Bayes 正答率増分が0.20以上。
- 各センサによる非対象状態の正答率増分の絶対値が0.03以下。

### G5 資源水準

- 観測予算2・表現スロット2の平均 Bayes 誤りが、全チャネル利用時の値と `1e-12` 以内で一致。
- 観測予算3または表現スロット3へ増やしたときの改善が `1e-12` 以下。
- 観測予算0・表現スロット1の平均誤りが、非拘束水準より0.10以上大きい。

## 進行条件

G1が不成立なら実装を修正するまで以降へ進まない。G2またはG3が不成立なら環境は競合源の
校正に不適切と判断し、III-A1へ進まない。G4またはG5が不成立なら観測・資源条件を使う
介入へ進まない。判定不成立を結果から除外せず報告する。
