# IV-E追加検証：レビュー後解析の証拠地位

作成日：2026年9月4日

`posthoc_review_analysis.py` は、固定済みの `results_confirm/*.csv` だけを読み、レビュー後に提案された次の量を再集計する。

- 二次モーメントの参加比
- 総量比から一様配置を仮定して得る平均逆スケーリング項の予測
- `scalar_v_own` を加えた四条件の再結合と交互作用
- optimizer条件別の10--500更新の時間プロファイル
- 配分指数の終点差と、形成終点からの低下量差

これらの条件自体は実行前に固定されていたが、この組合せと統計量は `protocol.md` の事前解析には含まれない。したがって結果はすべて探索的であり、確認的判定を置き換えない。

換算率 $k=\text{応答差}/(q\text{比}-1)$ も実行前計画に解析式として記載されていないため、条件平均間の探索的所見としてのみ扱う。seedごとの予測法則とはしない。

時間プロファイルでは、応答差と配分指数の終点差を区別する。応答差は「取得形成側の低下量－更新形成側の低下量」である。終点差は「取得形成側の配分指数－更新形成側の配分指数」であり、形成終点の小さな初期差を含むため、両者の数値と符号は一致しない場合がある。
