# IV-E追加検証：平均調整倍率だけでは短期応答差を説明できない

2026年9月3日。対象読者：研究者本人と共同研究者。

## 1. 何を確かめたか

Adamは、過去の勾配の二乗をパラメータごとに蓄積し、その値が小さいパラメータほど更新を大きくする。取得を偏らせて形成した学習器が、更新重みを偏らせて形成した学習器より短い介入に大きく反応することは、単に全体の更新倍率が違うためなのか。それとも、どのパラメータをどれだけ更新するかという配置にも意味があるのか。さらに、その差は長く介入しても残るのかを調べた。

結論は四つである。平均調整倍率は応答差の一部を予測したが、倍率をそのまま応答比とする近似は成立しなかった。平均倍率を揃えても二次モーメントの配置への介入が応答を変えた。二次モーメントの差は、累積勾配ノルムが近い更新系列を異なる長さのパラメータ更新経路へ変換し、この経路長差が短期応答差と強く対応した。大きな短期経路差は、長い反対条件やパルス後の均衡条件では小さくなった。

対象は二つの相関Gaussian信号を二次元共有表現へ圧縮する小規模tanhネットワークである。確認したのは、この系での形成後10更新の複合介入と、500更新までの反対条件継続、および10更新パルス後500更新の均衡継続である。

## 2. どのように比較したか

新しい40 seed（20000–20039）について、同じ初期状態から、取得非対称・均衡更新と、均衡取得・非対称更新の二経路を形成した。形成は従来と同じ100更新の初期学習と500更新。確認前に計画、コード、seed、測定時点、旧データで学習した予測式を固定し、全数を実行した。

形成後は各経路のモデル重みをそれぞれ複製し、Adamの状態を保つ、交換する、全体倍率を揃える、座標差をなくす、履歴を持ち越さない単純な勾配法（モーメンタムなしSGD）へ替える、という10条件を比較した。同じseed内では入力・batch順・介入前モデルが対応している。SGD条件でも形成自体はAdamで行っている。

主測定は、共通の高精度入力を与え、別データで線形readoutをfitした後、さらに別の評価データで測る配分指数sである。A/Bの鏡像はseed内で平均した。五つの形成終点指標はすべて事前許容幅内に入り、配分指数の経路差は−0.00352 [−0.00602, −0.00088]だった。ここで同等なのは指定した測定と許容幅の範囲であり、モデル重みや全内部状態の同一性ではない。

以下の区間はseed対応bootstrapによる個別95%区間である。±0.02を実質同等幅とし、区間がゼロを含むだけでは同等としない。

## 3. 全体倍率とパラメータ別の配置は、ともに応答へ作用した

応答は、反対対象を高精度で取得し、その誤差の重みを0.85にした10更新中に、形成時の優位側から配分指数がどれだけ低下したかで測った。表はその低下量の「取得形成−更新形成」の差である。

| 更新状態の条件 | 応答差 | 95%区間 |
|---|---:|---:|
| 元のAdam | 0.1907 | [0.1834, 0.1973] |
| mだけ交換 | 0.1929 | [0.1858, 0.1997] |
| vだけ交換 | −0.1183 | [−0.1263, −0.1102] |
| 平均倍率を揃え、vの座標比を保持 | 0.0875 | [0.0824, 0.0926] |
| 平均倍率を揃え、他経路のvの座標比を使用 | −0.0110 | [−0.0172, −0.0045] |
| 平均倍率を揃え、全座標のvを同じ値へ置換 | 0.0395 | [0.0343, 0.0449] |
| 各経路の元の平均倍率を保ち、vを一値化 | 0.1251 | [0.1187, 0.1318] |
| 新しいAdam | 0.0096 | [0.0075, 0.0120] |
| SGD、学習率0.002 | 0.0006 | [0.0005, 0.0007] |
| SGD、初回更新量で校正した共通学習率 | 0.0123 | [0.0102, 0.0145] |

元のAdam、v交換、Adam初期化について旧IV-Eのパターンが再現した。平均倍率を揃えると経路差は0.1032 [0.0993, 0.1069]縮んだが、残る0.0875は同等幅を超えた。その倍率を保ったままvの配置を交換した効果は0.0985 [0.0924, 0.1046]だった。したがって、全座標の平均倍率一つだけでは、今回の短期応答差を説明できない。

ここで揃えた倍率は、各パラメータのη/(√v̂+ε)の平均である。これは実際のパラメータ更新ノルムではない。vの配置は、現在の勾配やモデル重みとの組合せを通じて効く。倍率と配置を、独立に足し合わせられる二つの機構として分解した結果でもない。平均と全座標を揃えた条件に残る0.0395には、保持したm、モデル重み、介入後に再形成されるvの違いが含まれうる。

## 4. 単純な倍率予測は外れ、応答差の予測は一部改善した

旧40 seedでは、平均逆スケーリング項の取得形成／更新形成比は1.950だった。新規40 seedでは1.904 [1.871, 1.939]だったが、10更新応答の比は2.245 [2.187, 2.305]だった。各seedで「応答比＝調整倍率比」と置いた予測は、応答比を平均0.341 [0.292, 0.396]過小評価した。

旧データで係数を学習し、新規40 seedへ変更せず適用した線形予測では、倍率比から応答の差を予測すると、旧データ平均だけを使う予測に対して二乗誤差が34.2%減少した（RMSE 0.02339→0.01898）。関連はあるが、完全な予測ではない。

一方、応答の「比」を同じ倍率比から予測する回帰は、新規データでは平均だけの予測より悪く、二乗誤差が27.7%増えた。旧データ内の交差検証では改善していたため、この不成立は重要である。応答差と応答比は異なる目的変数であり、良かった方だけを一般的な予測則として採用しない。v総量比とmノルム比による予測も全件を`result.json`に保存した。

## 5. 実際の更新経路長が、短期応答差と強く対応した

保存済みの更新診断CSVだけを使い、元のAdam条件の最初の10更新を事後解析した。各seedでA/B鏡像方向を先にpoolして取得形成側を更新形成側で割ると、平均逆スケーリング倍率は1.900 [1.867, 1.935]、最初の一更新のパラメータ変位は2.028 [1.938, 2.116]、10更新の累積更新経路長は1.872 [1.844, 1.902]だった。一方、累積勾配経路長は0.987 [0.978, 0.996]だった。これは累積勾配ノルムの比較であり、座標別の勾配や方向が一致したことを意味しない。

seedごとの平均逆倍率比と10更新の更新経路長比の相関は0.797 [0.642, 0.890]、更新経路長の経路差と配分指数応答差の相関は0.806 [0.685, 0.889]だった。一つのseedを順に除外する交差検証では、平均逆倍率比を使う線形モデルが全seed平均だけの基準より応答差の二乗誤差を28.0%減らし、更新経路長差を使うモデルは62.0%減らした。後者は介入後に得た経路長による同時点の説明・再構成であり、形成終点からの事前予測ではない。最初の一更新の変位比と10更新応答比の相関は0.174 [−0.166, 0.520]であり、最初の一歩だけでは説明できなかった。

全10介入条件の平均では、更新経路長差と応答差の相関は0.994だった。これは同じseedとモデルを共有する条件平均の記述的比較であり、10個の独立標本としての検定ではない。効果の小さい五条件だけでは相関は0.702で、共通倍率・全座標一値化条件では経路長差0.0066に対して応答差0.0395が残った。また、更新経路長は介入後に生じる媒介候補で、形成終点だけから予測できる状態変数ではない。ノルムはパラメータ移動の方向も捨てる。結果は、形成履歴がAdamの二次モーメントを変え、そのプリコンディショニングが更新経路長と短期応答の差として現れる経路と整合するが、正式な媒介効果、形成履歴が残る単一の場所、配分変化の全機構は同定していない。

## 6. SGDでも十分に動かすと、小さい経路差が残った

学習率0.002のSGDは、10更新での配分指数低下が取得形成0.0053、更新形成0.0047に留まった。この条件のほぼゼロの経路差だけから、重み側の違いを排除することはできない。

そこで、最初の共通batchで計算したAdamの更新ノルムと勾配ノルムから、二経路に共通のSGD学習率を結果を見る前に定めた。この条件では低下量が0.0991と0.0868となり、実際に表現が動いた。その経路差0.0123は±0.02内だったが、ゼロではなかった。形成時のAdamを持ち越したときの大きな差はSGDへの交換で縮小し、小さい差は残った。

校正は最初のパラメータ更新ノルムの二経路幾何平均を合わせるもので、10更新全体の進行量、勾配の向き、将来の軌道を同一にするものではない。SGDで形成した学習器一般についての結論にも広げない。

## 7. 大きな経路差は長期の別状態を意味しなかった

元のAdamを保持して反対条件を続けると、応答差は10更新の0.1907から20更新の0.2353へ一度増え、50更新では0.0207となり、100更新の区間は±0.02内に入った。500更新の配分指数は取得形成−0.4331、更新形成−0.4326で、終点差は−0.00045 [−0.00142, 0.00058]だった。m交換、v交換でも大きな短期差が500更新まで続くことはなかった。

10更新で反対条件をやめ、取得・更新を均衡へ戻した別系列では、さらに500更新後の配分指数は0.0188と0.0090だった。その差0.00984 [0.00860, 0.01108]は実質同等幅内だが、ゼロを除く小さな差は残った。今回の短期の優位対象の入れ替わりは、そのまま長期間反対対象を優位に保つことを意味しなかった。

この結果は、指定した観測指標と500更新の終点についての結論である。全内部状態から履歴が消えたことや、無限時間の収束は検証していない。持続状態にもう一度介入した後の応答を比較すれば、長い継続後に別の痕跡が残るかを調べられる。

## 結論

平均的な調整倍率の差は、形成経路による応答差を小さくする有効な介入点だった。しかし、それだけでは差を説明できず、共通祖先から分岐した対応座標上の二次モーメント配置も、同じ平均倍率のもとで応答を変えた。実測した更新経路は、累積勾配ノルムが近い系列がAdamの履歴依存スケーリングを通ることで長さを変え、その長さの差が10更新の配分応答差と強く対応することを示した。その効果は短期の軌道へ強く現れ、長く続けた後の配分指数差は小さくなった。結果は主要な媒介候補と整合したが、形成経路の影響すべてが残る単一の場所、正式な媒介効果、任意の時間幅で応答を予測する完全な機構は同定できなかった。
