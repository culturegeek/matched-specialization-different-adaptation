# 実験I-C v0.2 リリースノート

## v0.1からの変更

- A/B信号にAR(1)時間相関 `phi` を導入
- `phi = 0, 0.4, 0.8` の比較を追加
- 母集団共分散から全16スケジュールの目的値を厳密計算
- 時刻別加法モデルの最大絶対残差とRMSEを追加
- Hamming-1局所最適の列挙を追加
- 全スケジュールからの貪欲改善による吸引域解析を追加
- 初期値を広くし、学習方策のOracle到達率と収束先分布を追加

## full設定の主要結果

`lambda=0.5` において、

- `phi=0`：最大加法残差 (3.3\times10^{-16})、局所最適1個、大域解 `AABB`
- `phi=0.4`：最大加法残差0.047750、局所最適1個
- `phi=0.8`：最大加法残差0.217266、局所最適 `AABB` と `ABAB`
- `phi=0.8`の大域的貪欲吸引域は16初期点中12点（0.75）
- 共同更新方策のOracle到達率は0.65
- 共同更新はランダム方策より0.2234、下流固定条件より0.0434改善

時間相関だけの追加により、目的関数は時刻ごとの独立な和ではなくなり、局所最適と初期値依存が現れた。

## 次段階

現在の観測履歴または信念状態を方策へ入力し、閉ループ方策を導入する。v0.2の開ループ条件を対照に残し、状態依存性そのものの利得を分離する。
