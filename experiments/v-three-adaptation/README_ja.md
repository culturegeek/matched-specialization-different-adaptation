# V-B：三対象での適応と状態交換

何を精密に表現しているかが近くても、次の学習で動く程度は異なるのか。この問いを、三対象の六つの移行方向で確かめた。

調整用8 seedの終点測定だけから、両容量とも更新経路の標的重み0.65を選んだ。未使用40 seedを容量2・3で共用して確認した。両容量で八つの終点同等性基準を満たした。10更新の応答差は、容量2で0.1945からv交換後-0.1005へ、容量3で0.4054から-0.2193へ反転した。平均逆倍率を揃えた交換効果も残った。初期化同等性は容量2で成立し、容量3では区間が上限0.02を跨ぐため未確定だった。

元標的から行先への二対象の指数だけでなく、第三対象を含む三配分得点、全六方向、50更新までの軌跡も保存した。50更新では引継ぎ状態の対比が縮小し、初期化後の差が相対的に大きくなった。この結果は固定した三対象人工系と有限時間の範囲にある。

計画・全校正候補・ローカル固定・生データ・集計は同フォルダにある。確認実験40 seedを全て保持した。独立監査1,603項目が通過した。計画の固定は公開レジストリへの事前登録ではない。再実行手順はREADME.mdを参照する。読者向け説明は統合105報告と論文に収録する。
