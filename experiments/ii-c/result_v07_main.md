## 0. 総括

**12件中11件が PASS、1件（G5-11）が FAIL。** 主判定である G1（後期定常性）と G2（有限の吸引域）は完全に成立した。転換率は $K=0$: **0.000** → 800: **0.200** → 1600: **0.425** → 3200: **0.650** と明瞭な用量反応を示し、復帰個体は元の水準の 0.985 倍へ、転換個体は反対枝で 1.015 倍へ、転換個体の 100% が内点に到達した。

これにより、**容量2の二枝は「終端分布の記述」から「有限の吸引域を持つ状態」へ格上げされた。** 準安定レジームの操作的要件のうち、(i) 内点の定常性（G1）、(ii) 摂動からの復帰（G3）、(iii) 十分に強い摂動による別状態への転換（G2）、(iv) 転換先が対称な同型の状態であること（G3）が、独立 seed の事前登録実験で揃った。残るはヒステリシス（外部バイアスの往復）である。

G5-11 の FAIL は、機構候補だった不得意ヘッド距離の予測力の否定であり、重要な負の結果である（§5）。

## 5. G5 機構診断 — 重要な負の結果

**G5-11 FAIL：$K=1600$ の内部で、不得意ヘッド距離は転換を予測しない。** AUC = 0.373（転換17 vs 復帰23、判定 ≥0.70）。0.5 を下回っており、方向としてはむしろ復帰群のほうが距離が大きい。v0.7.1 の「候補指標」は、$K$ の代理としては機能するが、$K$ を固定した個体差の予測子としては否定された。ChatGPT の指摘（プール相関は $K$ の代理）が正しかったことが、独立 seed で確定した。

G5-12 PASS：Adam keep/reset の帰結一致率 0.875（≥0.80）。Adam 状態が主要因でないことも独立 seed で再現。

### 探索的追記（事前登録外、次の設計用）

$K=1600$ 内部で何が転換を予測するかを、記録済みの量で走査した：

| 予測子（rel=0 時点） | AUC |
|---|---:|
| 分岐時の枝の深さ $\|s_{\text{pre}}\|$ | 0.312（浅いほど転換） |
| 不得意ヘッド距離 | 0.373 |
| エンコーダ距離 | 0.399 |
| CKA対分岐 | 0.542 |
| 揃えた $s$ | 0.588 |
| **揃えた $s$（rel=25）** | **0.749** |
| **揃えた $s$（rel=100）** | **0.834** |
| **揃えた $s$（rel=400）** | **0.995** |

摂動終了時点のどの記録量も帰結をほぼ予測しない（枝の深さがわずかに逆向きの信号を持つ程度）。一方、**回復開始からわずか25ステップ後の $s$ は AUC 0.749、100ステップ後には 0.834 に達する**。帰結の情報は摂動終了時の状態の「どこか」にはあるはずだが（力学は決定的＋共通乱数）、記録している要約量には現れず、回復動力学が始まった直後に初めて読み出せる形になる。転換の運命は静的な状態量ではなく、**回復初期の応答**に最も早く現れる。これは次の機構実験（得意側ヘッドへの介入、勾配応答の測定）の設計に使える観察である。

## 6. 何が言えて、何が言えないか

### 言えること（すべて事前登録判定、独立40 seed）

1. 容量2の安定化型の内点二枝は、後期窓（8000→16000）で定常である。自発転換は 40 seed でゼロ。
2. 二枝は有限の吸引域を持つ。弱い摂動（$K=800$）からは 8 割が復帰し、強い摂動（$K=3200$）では 65% が転換する。転換率は摂動の累積量に対して単調に増える。
3. 復帰でも転換でも、系は同じ大きさの内点水準へ戻る。枝は符号だけが違う対称な対である。
4. 摂動終了時のプローブ指数と両復号誤差は $K$ 間でほぼ同一であり、これらの表面指標では帰結を記述できない。
5. Adam 状態は帰結の主要因ではない（一致率 0.875）が、回復を約4倍速める。
6. 不得意ヘッド距離は、$K$ を固定した個体差の予測子ではない（AUC 0.373）。

### 言えないこと

1. **ヒステリシスは未測定。**外部バイアスを往復させたときの経路依存（行きと帰りで転換点が異なること）は、次の実験の対象である。
2. **記憶の所在は未特定。**Adam でないこと、記録した要約量（$s$、誤差、ヘッド/エンコーダ距離、CKA）に現れないことまでが確定。どの重み成分が帰結を因果的に担うかは、介入実験（得意側ヘッドへの雑音・再初期化等）を要する。
3. 「準安定レジーム」の語は、ヒステリシスの確認までは正式採用しない。現時点の正確な記述は「**有限の吸引域を持つ、対称な二つの内点状態**」である。
4. 単一の合成環境・単一の選択則での結果である。
