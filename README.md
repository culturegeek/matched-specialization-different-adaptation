# Matched Specialization, Different Adaptation

Code and generated data for **Matched Specialization, Different Adaptation: Second-Moment Structure in Shared Representations**, by Toru Takahashi (manuscript revision: 16 October 2026).

Can two learned representations with similar measured specialization respond differently to the same new learning conditions? In a controlled synthetic learning system, the answer is yes. Adam stores running averages of squared gradients, called its second-moment state, which help set the size of each parameter update. Swapping this state reverses the short-horizon contrast between two formation routes. Matching the average factor by which this state scales parameter updates reduces, but does not remove, that contrast. The timing of adaptation also changes with the optimizer state used for continuation.

These experiments establish these effects in the tested synthetic systems. Formation uses Adam; SGD is tested as a continuation optimizer. The three-target Gaussian extension now reproduces the matched-endpoint state-swap effect at two capacities. A natural three-room sensor extension retains component effects but fails endpoint matching. The stored negative results and exploratory analyses are included alongside the confirmatory results.

## Start with the stored results

Download the repository or clone it:

```sh
git clone https://github.com/culturegeek/matched-specialization-different-adaptation.git
cd matched-specialization-different-adaptation
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-analysis.txt
python scripts/verify_data.py
python scripts/check_core_results.py
python scripts/make_figures.py
```

The first check verifies the preserved source files and the frozen follow-up records. The second independently recomputes 27 central manuscript means from CSVs. The final command regenerates the five English figure families in `generated/figures/`. This route requires no training or GPU. Expected figure assets are in [paper/figures](paper/figures).

The repository includes per-seed trajectories and formation checkpoints. Most observations are generated by the supplied synthetic systems. The natural extension redistributes the UCI Appliances Energy Prediction dataset under its original CC BY 4.0 attribution; no additional download is needed.

## Reproduce training

The [reproduction guide](docs/REPRODUCING.md) gives a one-seed reproduction check, the 40-seed follow-up, and commands for the core intervention studies. Use a new output directory for each rerun. The original experiment programs, plans, and canonical numerical results are preserved; the public figure and arithmetic-check scripts use portable repository-relative paths.

The follow-up's original environment was Python 3.11.7, PyTorch 2.13.0, NumPy 2.4.6, CPU, one thread. Recorded dependencies are in [requirements-recorded-training.txt](requirements-recorded-training.txt). The environment and checks used to validate this publication are recorded separately in [validation](provenance/validation.json).

## Evidence and provenance

The unit of inference for the main route contrasts is the random seed; mirrored target directions are averaged within each seed. The follow-up uses 40 seeds, 20000–20039. Its time-stamped, hashed plan was fixed locally before execution; it was not registered in a public registry. Files named `posthoc_*` and `POSTHOC_*` document later exploratory analyses. Figure bootstrap intervals have their own documented random stream and do not replace confirmatory intervals.

[Source provenance](provenance/source_files.json) maps the released files to the archived experiment packages. One obsolete workstation path in an Experiment III metadata file was replaced with `SOURCE_ROOT`; its numerical content and experiment-code checksum are unchanged. The manifest records this transformation. Operating-system metadata and private review records are omitted. Superseded scientific runs, failed criteria, and negative findings remain in the experiment evidence folders.

## IV-F extension (16 October 2026)

[IV-F](experiments/iv-extension/README.md) adds endpoint prediction in three existing 40-seed cohorts, 32 new paired seeds across nine settings, and layer/movement interventions on 40 saved seed pairs. V exchange reverses the contrast under changed width, nonlinearity, and target correlation; reset equivalence fails at width 64. The beta2/duration grid further limits reversal and reset equivalence. A component effect remains under equal global movement. All failed criteria are retained.

With the recorded training environment, run `python experiments/iv-extension/audit_extension.py` for its independent raw-data and integrity checks. [Interval audit](docs/INTERVAL_AUDIT.md) links every printed interval to a source, including three newly reconstructed exploratory intervals. These additions do not change the original frozen experiment results.

## V-B and V-C extension (v1.2.0)

[V-B](experiments/v-three-adaptation/README.md) uses 40 new seeds at two capacities and all six directions. Matched endpoints coexist with reversed response contrasts under second-moment exchange; common-scale pattern effects remain. Reset equivalence at capacity three is unresolved. [V-C](experiments/v-natural/README.md) follows with 40 separate seeds on one building's three-room temperature/humidity records. Endpoint matching fails; state-exchange effects remain positive, including at common scale. This is a partial transfer of the intervention effect, not a natural matched-endpoint replication. Full failed criteria and 50-update results are retained.

Run `python experiments/v-three-adaptation/audit_adaptation.py` and `python experiments/v-natural/audit_natural.py` for independent checks. See [natural dataset attribution](experiments/v-natural/data/ATTRIBUTION.md). The original v1.1.0 release remains fixed.
