# Final checks for manuscript v1.5.1

No new hypothesis-driven training cohort was added. The fixed 40 projection seeds and all five recorded horizons (1, 5, 10, 20, 50) were independently reaggregated from CSV, reproducing all 150 response estimate components. The saved formation trace decomposition is exploratory; it uses beta2=0.999 exponential weights, direction-specific ratios, a log average within seed, and a geometric mean over all 40 seeds. Individual gradients shrink under projection while their sum grows. This does not isolate cancellation from magnitude or trajectory changes.

Run `python analyses/final_checks_20261017/reaggregate.py --archive-root . --out /tmp/final-checks` from the archive root. Output is written separately from frozen evidence. Every input is listed with its SHA-256 in result.json.

Both audit scripts now default to strict floating comparison and accept explicit `--tolerance 1e-6`. Weights and first moments use tolerance*(1+max(abs(reference))); second moments use 1e-12+tolerance*max(abs(reference)). Shape, dtype, finiteness, nonnegative v, schedules, step counts, source locks and exact transplant identity are not relaxed. No automatic tolerance increase occurs. Optional --seeds selects a declared subset; JSON records the seeds and full_cohort flag.

On this arm64 CPU, Python 3.12.14 / NumPy 2.4.6 with PyTorch 2.13.0 passed both full 40-seed audits strictly. A separate PyTorch 2.14.1 installation passed the 40-seed projection audit with tolerance enabled (actual differences were zero), plus formation replay and strict/tolerant audits for seed 20000. A strict projection audit also passed on seed 38000. This does not reproduce a reviewer machine's nonzero differences or promise cross-machine bitwise equality. Eleven controlled numeric checks additionally verify rejection of excessive errors, malformed tensors and invalid tolerances, while accepting an explicit one-ULP weight difference only in tolerance mode. Preserved historical training logs and registered training-source hashes remain unchanged.
